# 7032 Alternative ROMs

7032 Alternative ROMs は、FM-7 / FM77AV 系パソコンのエミュレーターで使う代替 ROM 一式です。機種ごとに選んで置く ROM 15 本を収録しており、機種に元から載っていた ROM が無くても BASIC が立ち上がります。参考書籍と動作観察を基に書き起こした独立実装です（[docs/LEGAL.md](docs/LEGAL.md) §6）。アセンブラソースを持つ ROM はすべて MIT ライセンス・ソース公開です。

配布物のバージョンは **v1.0.0** です（[CHANGELOG.md](CHANGELOG.md)）。

## 収録物

| 区分 | 本数 | 内容 |
| --- | ---: | --- |
| 代替 ROM | 12 本 | 起動、サブ CPU 側のサブシステム、CG（フォント）、BASIC インタプリタ本体（7T-BASIC 3.1）。MIT ライセンス・ソース公開 |
| データ ROM | 3 本 | 16x16 漢字フォント（第一水準・第二水準）と、辞書 ROM の枠 |

ビルド済みのファイルは [roms/](roms/)、ソースは [src/](src/)、ビルド定義は [Makefile](Makefile) にあります。1 つの環境に置くのは最大 12 本です（同じ枠の機種別変種は、機種に合う 1 本だけを置きます）。

## 使ってみる

1. [roms/](roms/) の ROM ファイルを手元に置きます（GitHub の「Code」→「Download ZIP」でリポジトリをまるごと取得して展開します）。
2. ブラウザで試すなら、実行環境 [WebM7](https://7032jp.github.io/WebM7/) を開きます（[docs/SETUP.md §3](docs/SETUP.md#3-ブラウザで試すインストール不要)）。手元のエミュレーターで使うなら、機種別コピー表のとおりの名前で ROM 配置先へコピーします（[docs/SETUP.md §4](docs/SETUP.md#4-機種別コピー表)）。
3. 画面にタイトル 2 行（1 行目は青い帯の上の `7T-BASIC version 3.1`、2 行目は著作権行）と空きバイト数の行に続いて `Ready` が出れば BASIC が動いています。

BASIC ROM は多くの環境が `fbasic30.rom` という名前で読みます。`7tbasic3.rom` をこの名前に変えて置く点が、いちばん間違えやすいところです。

## 何が動くか

- 起動（BASIC モード・ディスク起動）、画面表示、キー入力、図形描画、音が動きます。カセットとディスクは、プログラムと機械語の読込み・保存（`LOAD` / `SAVE` / `LOADM` / `SAVEM` / `MERGE` / `CHAIN` / `FILES`）に対応します。ファイルの入出力は、キーボード（`KYBD:`）と画面（`SCRN:`）を `OPEN` / `CLOSE` で開閉するところまでに対応します。雑誌や書籍に載っている FM-7 用の BASIC プログラムも、対応している文法の範囲で打ち込んで動かせます。
- BASIC プログラムの保存はアスキー形式（`SAVE ,A` と同じ形式）だけです。中間コード（バイナリ）形式で保存されたプログラムは読み込めません。
- かな漢字変換（日本語入力）と、拡張サブシステムの機能部は未対応です。
- 機能ごとの対応、予約語ごとの対応、動かないプログラムの種類は [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md) にあります。
