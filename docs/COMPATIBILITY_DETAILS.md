# COMPATIBILITY_DETAILS — 機能ごとの対応表

[COMPATIBILITY.md](COMPATIBILITY.md)（実機との違い）の詳しい表です。区分は `✅ 対応` ／ `✗ 未対応` で、一部だけ対応する機能は未対応の範囲を書き添えます。データ ROM は区分を持たないので `—` です。

## 1. 機種の仕組み

ブート ROM・イニシエータ ROM・サブシステム ROM が担う、ハードウェア（機種）としての互換性です。オーダの文字・行入力のカーソルの点滅・STATUS のビット割当てなど、各項目の細かい動きは [BUILD.md](BUILD.md) §5.7 にあります。

| # | 機能 | 担う ROM | 状況 | 対応する範囲／未対応 |
| --: | --- | --- | :---: | --- |
| 1 | 電源 ON からの起動（BASIC モード） | FM-7 系: `boot_bas` ／ FM77AV 系: イニシエータ ROM | ✅ 対応 | 電源 ON / リセットから BASIC ROM へ制御を渡すまで。FM77AV 系は表示面・パレット・サウンド・MMR の初期化と、機種識別域の提示を含みます（[BUILD.md](BUILD.md) §5.5） |
| 2 | ディスク起動（IPL からの起動） | `boot_bas` / `boot_dos` ／ イニシエータ ROM | ✅ 対応 | 起動セクタ（トラック 0・セクタ 1）を読んで IPL へ制御を渡します。起動対象ドライブは [SETUP.md](SETUP.md) §2.5。未対応: フロッピー以外からの起動 |
| 3 | FDC の読み書き | `boot_bas` / `boot_dos` ／ イニシエータ ROM | ✅ 対応 | セクタ単位の読み書きと、トラック 0 への復帰（[BUILD.md](BUILD.md) §5.2） |
| 4 | サブシステムの共有 RAM コマンド | `subsys_c` ／ `subsys_a` / `subsys_b` | ✅ 対応 | コマンドは [BUILD.md](BUILD.md) §5.4・§6.2、文字表示の中に置くオーダは §5.7。未対応: 時計の読み書き（`$41` / `$42`）と一覧に無いコードは、エラーコード `$46` を返して何もしません |
| 5 | 行入力（GET） | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | フィールドの中での上書き・挿入・削除・カーソル移動・上の行の複写・取消し（CTRL+C / CTRL+X）に対応し、変更したフィールドを画面の上から順に返します（1 行 255 文字まで）。未対応: SHIFT を併用した単語・フィールド単位の移動 |
| 6 | サブ CPU への機械語の転送と実行 | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | 共有 RAM 経由の転送・呼出・停止 |
| 7 | グラフィックカーソル | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | ＋印の移動と、改行キーによる座標の読取り（10 個まで）。未対応: SHIFT を併用した 20 ドット単位の移動 |
| 8 | 画面モード 640×200 / 8 色 | `subsys_c` ／ `subsys_a` / `subsys_b` | ✅ 対応 | 3 プレーン・色番号 0〜7。テキストは 40 / 80 桁 × 20 / 25 行で、文字ごとのアトリビュートを持ちます |
| 9 | 画面モード 320×200 / 4096 色 | `subsys_b` | ✅ 対応 | 文字表示（40 桁 × 25 行）・点列・文字パターン・直線・矩形・塗りつぶし・矩形の読み書きを描きます（[BUILD.md](BUILD.md) §5.4・§5.7）。未対応: 色置換・グラフィックカーソルなどは 8 色の画面の並びで描き、かな書体の切替・描画モードなどはエラーコード `$46` を返します |
| 10 | 画面モード 640×400 と 26 万色 | — | ✗ 未対応 | サブシステム ROM に処理はありません。イニシエータ ROM は機種識別域でこのモードを備える世代を示すだけです |
| 11 | 表示ページ・処理ページの選択と描画範囲 | `subsys_a` / `subsys_b` | ✅ 対応 | ページの選択（`$22`）と、描画範囲を決める枠付きの矩形の塗り（`$39`）（[BUILD.md](BUILD.md) §5.4・§5.7）。未対応: 選択の読み返し（`$24`） |
| 12 | 時計（時刻の進行） | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | タイマの設定と読出し。サブ CPU が時・分・秒を進めます |
| 13 | キー入力の禁止・キーバッファの消去・先行入力 | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | 文字表示の中のオーダで指示します。電源投入時は先行入力を許可した状態です |
| 14 | ベル | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | BEL（`$07`）・ページリミット・保護されたフィールドへの入力でブザーを鳴らします |
| 15 | メイン CPU への割込み通知（ATTENTION） | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | 機能キー・タイマ・インターバルタイマの事象を割込みで知らせ、BASIC の `ON KEY(n) GOSUB` / `ON INTERVAL GOSUB` へ繋ぎます。転送した機械語の走行中は知らせません |
| 16 | コマンドの中止（COMMAND ABORT） | `subsys_c` / `subsys_a` / `subsys_b` | ✅ 対応 | 実行中のコマンドを捨てて、次のコマンドを待ちます |
| 17 | 表示の ON / OFF | `subsys_c` / `subsys_a` / `subsys_b` | ✗ 未対応 | 起動時に表示を点灯するだけで、以後の ON / OFF は操作しません |
| 18 | テープ入出力の機構 | `7tbasic3` | ✅ 対応 | ブロック形式の読み書き（[BUILD.md](BUILD.md) §5.3）。未対応: ジッタの大きいテープイメージ |
| 19 | 機械語からの入出力サービス（`JSR [$FBFA]`） | `7tbasic3` | ✅ 対応 | リクエスト番号 1〜3・8〜10・12・13・16〜22・24（[BUILD.md](BUILD.md) §5.2・§5.7）。未対応: プリンタ関係（5・14・15・23）とリザーブの番号は `Device Unavailable` |
| 20 | 漢字フォント・辞書・ANK フォント | データ ROM 3 本と CG ROM・拡張サブシステム ROM | — | 収録内容は §5。かな漢字変換は未対応です |
| 21 | 拡張サブシステム（FM77AV40EX / AV40SX） | `extsub` | ✗ 未対応 | 所定サイズと ANK 字形を供給する枠だけです（[SETUP.md](SETUP.md) §2.6） |

画面モードの切替は、メイン CPU 側のソフトウェアがレジスタへ書いて行います。切り替わるとサブ CPU は初期化されます。

## 2. BASIC

BASIC ROM（`7tbasic3`）が担う、言語の文法と動作の互換性です。文法の詳細は [BASIC_REFERENCE.md](BASIC_REFERENCE.md)（以下「リファレンス」）にあります。

| # | 機能 | 状況 | 対応する範囲／未対応 |
| --: | --- | :---: | --- |
| 1 | `WIDTH` / `CONSOLE` | ✅ 対応 | 40 / 80 桁 × 20 / 25 行、スクロール領域・機能キー行・単色表示（リファレンス §4.2）。起動直後は 40 桁 × 20 行 |
| 2 | `SCREEN` 文と関数 | ✅ 対応 | 書き込み面・表示面の選択と、関数形 `SCREEN(X,Y[,SW])`（リファレンス §4.2・§7.1） |
| 3 | FM77AV 系のアナログモードとパレットの文 | ✗ 未対応 | 文は 640×200 / 8 色の画面が対象です。F-BASIC V3.0 の予約語に無いので §3 の数え方に含めません |
| 4 | コンソール | ✅ 対応 | `PRINT` / `LOCATE` / `COLOR` / `INPUT` / `LINE INPUT` / `INKEY$` / `KEY`（リファレンス第 4 章）。時間の掛かる動作の最中に打ったキーも順に受け取れます |
| 5 | カセット | ✅ 対応 | `LOAD` / `LOAD?` / `SAVE` / `LOADM` / `SAVEM` / `CHAIN` / `MERGE` / `SKIPF` / `MOTOR` / `FILES "CAS0:"`（リファレンス第 2 章）。装置名を省くと `CAS0:` です |
| 6 | ディスク | ✅ 対応 | `LOAD` / `SAVE` / `LOADM` / `FILES`（リファレンス第 2 章）。装置名 `0:` / `1:` は省けません。書式は 2D で、ファイルは 152 個までです（[BUILD.md](BUILD.md) §5.3） |
| 7 | ディスクのファイル入出力とディスクの管理 | ✗ 未対応 | ディスクを指す `OPEN` は `Device Unavailable`、`EOF` / `LOF` は常に 0、`KILL` は何もしません（リファレンス §4.8・第 10 章）。`NAME` / `DSKINI` / `DSKF` は予約語として持たず、変数名になります |
| 8 | グラフィック | ✅ 対応 | 640×200 / 8 色の画面への描画と、画面と配列の間の転送（リファレンス第 5 章） |
| 9 | サウンド | ✅ 対応 | `PLAY` の 3 声・`SOUND`・`BEEP`（リファレンス第 6 章） |
| 10 | タイマ・時刻 | ✅ 対応 | `TIME$` の設定と進行、`DATE$` の設定、`INTERVAL` と `ON TIME GOSUB` の割込み（リファレンス §4.5・§4.6）。未対応: `DATE$` の自動の進行 |
| 11 | 数値演算・数値関数 | ✅ 対応 | 整数・単精度・倍精度（16 桁）の演算と `PRINT USING`（リファレンス第 1・7・8 章）。未対応: 超越関数・べき乗・`FIX` / `CINT` は倍精度の引数を単精度へ落として計算します |
| 12 | プログラムの編集 | ✅ 対応 | `AUTO` / `DELETE` / `UNLIST` / `EDIT` / `RENUM` と、キーワードの省略形 16 語（リファレンス第 1・2 章）。`EDIT` の操作は §1 #5 と同じです |
| 13 | プログラムの保存・読込 | ✅ 対応 | アスキー形式だけです（[COMPATIBILITY.md](COMPATIBILITY.md) §3）。保護保存 `,P` は互換性の保証対象外です |
| 14 | 周辺装置 | ✗ 未対応 | プリンタ・バブルカセット・RS-232C の文は受理して何もせず、`PEN` は `Device Unavailable`、`ANPORT` は 255 を返します（リファレンス第 10 章・§7.1） |
| 15 | かな漢字変換 | ✗ 未対応 | 辞書 ROM は空の枠です（§5） |

## 3. BASIC 予約語の対応

F-BASIC V3.0（ROM モード）の予約語 146 語の対応です。語ごとの挙動と数え方はリファレンスの冒頭と第 10 章にあります。

| 区分 | 件数 | 語 |
| --- | --- | --- |
| 対応 | 下の 18 語を除く残り | リファレンス第 1〜9 章 |
| 対象外 | 8 語 | `LLIST` / `LPRINT` / `LPOS` / `HARDC` / `BUBINI` / `BUBW` / `BUBR` / `MON` |
| 未対応 | 10 語 | `COM` / `COMMON` / `EOF` / `LOF` / `KILL` / `PEN` / `RSET` / `TERM` / `TRON` / `TROFF` |

ディスクモード専用の語（`CVI` / `FIELD` / `LSET` / `DSKF` 等）は 146 語に入りません。第 10 章はディスクの管理の 3 語（`DSKF` / `DSKINI` / `NAME`。対象外）も載せ、全体で 21 語です。

## 4. 機種構成ごとの対応

| 機種構成 | 置くイニシエータ ROM（と機種固有の ROM） | 起動・BASIC | 26 万色モード | ソフト互換 |
| --- | --- | :---: | :---: | :---: |
| FM-7 系 | （ブート ROM を使用） | ✅ | — | ✅ |
| FM77AV 基本機 | `initav1`（ディスク起動はドライブ 0 のみ） | ✅ | — | ✅ |
| FM77AV20 | `initbase` | ✅ | — | ✅ |
| FM77AV40 | `initiate` | ✅ | ✗ | ✅ |
| FM77AV20EX | `initex` | ✅ | — | ✅ |
| FM77AV40EX / AV40SX | `initex` ＋ `extsub` ＋ `dicrom` | ✅ | ✗ | ✅ |

「ソフト互換」は、§1・§2 の対応機能を使う BASIC プログラムと機械語プログラム（言語動作・画面描画・入出力）が対象です。`—` はその機能を持たない機種です。

## 5. データ ROM とフォントの収録内容

| ROM | 何が入っているか |
| --- | --- |
| `kanji.rom` | 16x16 漢字フォント・第一水準。JIS X 0208 の 1〜7 区と 16〜47 区は全 94 点、8〜15 区は 32〜63 点だけに枠があります。1〜8 区の 107 符号位置は本プロジェクトの独自書き起こし、それ以外は第三者のパブリックドメイン宣言つきフォントです（[LEGAL.md](LEGAL.md) §9.2） |
| `kanji2.rom` | 同・第二水準。48〜87 区は全 94 点、88〜94 区は 32〜63 点だけに枠があり、字形の無い符号位置はゼロ埋めです |
| `dicrom.rom` | 辞書 ROM の枠（262144 バイト、全域 `0x00`） |
| `subsyscg.rom` ／ `subsys_c.rom` の先頭 2KB | 8x8 ANK フォント 256 字（`subsyscg` は 4 バンクに同じ字形）。字形は本プロジェクトの独自設計で、収録する字の範囲は [LEGAL.md](LEGAL.md) §8.1 にあります |
| `extsub.rom` | 8x16 ANK フォント（8x8 の縦 2 倍）と 8x8 ANK フォント × 3 区画。残りはゼロ埋めです（[BUILD.md](BUILD.md) §5.6） |
