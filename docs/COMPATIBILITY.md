# COMPATIBILITY — 何がどこまで動くのか

代替 ROM で何がどこまで動くかをまとめています。

1. **参考書籍（[LEGAL.md](LEGAL.md) §6.1）を基本仕様**として実装しています。起動・画面表示・キー入力・カセット読込と、F-BASIC の標準的な文法・動作を対象とします。対応する範囲と未対応の範囲は §1 の表のとおりです。
2. **対応する固定エントリポイントは [BUILD.md](BUILD.md) §5.2 の一覧に限ります**。一覧に無いアドレスを直接呼ぶプログラムは動きません（§3）。
3. **プログラムの保存はアスキー形式だけです**。中間コード（バイナリ）形式で保存された BASIC プログラムは読めません（§3.2）。

## 1. 機能ごとの対応

互換性は 2 層に分けています。

| 層 | 何の互換性か | 担う ROM |
| --- | --- | --- |
| §1.1 機種の仕組み | ハードウェア（機種）のシミュレータとしての互換性。起動・FDC・サブシステムのコマンド・画面モード・時計 | ブート ROM・イニシエート ROM・サブシステム ROM |
| §1.2 BASIC | ROM に左右される互換性。言語の文法と動作 | BASIC ROM（`7tbasic3`） |

区分は `✅ 対応` ／ `✗ 未対応` の 2 つです。一部だけ対応する機能は、対応する範囲と未対応の範囲を分けて書いています。プログラムでないデータ ROM（フォント・辞書）は対応の区分を持たないので `—` です。

| 18 | テープ入出力の機構 | `7tbasic3`（メイン CPU 側の入出力ポートを直接駆動） | ✅ 対応 | 対応: 信号の読み書きと、ヘッダ・データ・終端からなるブロック形式（識別子・ブロック種別・長さ・データ・検査和の並び。ヘッダブロックのデータは 20 バイトで、その内訳は本実装の `SAVE` / `SAVEM` と対になります）。読込みではヘッダブロックを読み終えた時点で、その内容（ファイル名・ファイル形式・属性）を 1 行表示します。未対応: 信号のばらつき（ジッタ）が大きいテープイメージ（§3.1 (c)） |
| 19 | 機械語からの入出力サービス（`JSR [$FBFA]`） | `7tbasic3` | ✅ 対応 | 対応: リクエスト番号 1（MOTOR）・3（CTBRED）・8（RESTOR）・10（DREAD）・16（SUBOUT）・20（OUTPUT）・21（KEYIN）。未対応: 上記以外の番号は `Device Unavailable`（エラーステータス 2）を返します |
| 20 | 漢字フォント ROM・辞書 ROM・ANK フォント | データ ROM 3 本（`kanji` / `kanji2` / `dicrom`）と、CG ROM・拡張サブシステム ROM の ANK フォント | — | 収録内容は §5。かな漢字変換は未対応です |
| 21 | 拡張サブシステム（FM77AV40EX / AV40SX） | `extsub` | ✗ 未対応 | 所定サイズと ANK 字形を供給する枠で、拡張サブシステムの機能部はありません（[SETUP.md](SETUP.md) §2.6） |

画面モードの切替（サブシステム ROM の選択）は、メイン CPU 側のソフトウェアがレジスタへ書いて行います。切り替わるとサブ CPU は初期化されます。BASIC ROM からの切替は §1.2 #3 です。

## 2. BASIC 予約語の対応

文法の基準は F-BASIC V3.0（ROM モード）で、その予約語 146 語の対応状況です。

| 区分 | 件数 | 所在 |
| --- | --- | --- |
| **対応（○）** | 未サポートを除く残り | [BASIC_REFERENCE.md](BASIC_REFERENCE.md) 第 1〜9 章の各表 |
| **対象外（ROM モード）** | 8 語 | [BASIC_REFERENCE.md 第 10 章](BASIC_REFERENCE.md#10-未サポートの予約語) の一覧。プリンタ（`LLIST` / `LPRINT` / `LPOS` / `HARDC`）・バブルカセット（`BUBINI` / `BUBW` / `BUBR`）・モニタ（`MON`） |
| **未対応（ROM モード）** | 10 語 | 同上の一覧。`COM` / `COMMON` / `EOF` / `LOF` / `KILL` / `PEN` / `RSET` / `TERM` / `TRON` / `TROFF` |

- 数え方と、未サポートの語ごとの挙動（無視・エラー・常に 0）は [BASIC_REFERENCE.md](BASIC_REFERENCE.md) の冒頭と第 10 章にあります。
- ディスクモード専用の語（`CVI` / `FIELD` / `LSET` / `DSKF` 等）は、V3.0・ROM モードの予約語に入らないので、この 146 語には数えていません。第 10 章の一覧には、ディスクの管理で使う `DSKF` / `DSKINI` / `NAME` の 3 語も補足しています。この 3 語は対象外で、一覧全体では対象外 11 語・未対応 10 語の 21 語です。

## 3. 動作の範囲と制限

### 3.1 区分ごとの動作範囲

| 区分 | 内容 | 帰結 |
| --- | --- | --- |
| (a) 対応する標準機能 | 起動・カセット読込・画面表示・キー入力・F-BASIC の標準的な文法と動作 | 対応・未対応の内訳は §1 |
| (b) 未対応の固定入口への直接依存 | 未実装のルーチンをアドレス指定で直接 `JSR` するプログラム | **動作しません**。そのアドレスに呼び出す処理がありません。対応する固定入口は [BUILD.md](BUILD.md) §5.2 の一覧に限ります |
| (c) カセット読込の精度 | 信号のばらつき（ジッタ）が大きいテープイメージ | 読み取りに誤差が出ることがあります |
| (d) 文言・既定文字列 | 起動時の表示、案内文 | 起動時はタイトル 2 行（`7T-BASIC version 3.1` と著作権行）と空きバイト数の行を表示した後に `Ready` を表示します。テープの読込みでは、ヘッダブロックの内容（ファイル名 8 桁・空白 2 個・ファイル形式 1 桁・空白・属性 1 文字）を 1 行表示します |

### 3.2 プログラムの格納・保存形式

本実装は、BASIC プログラムを **ASCII のテキストとして**格納します。予約語の省略形は入力時に完全形へ展開し、それ以外の綴り・空白・大小文字は保ちます。`SAVE` / `LOAD` / `MERGE` は**アスキー形式**（`SAVE ,A` と同じ形式）だけを扱います（[BUILD.md](BUILD.md) §5.3）。

- バイナリ形式（`SAVE` で `,A` を付けずに保存したもの）の BASIC プログラムのファイルは読み込めません（`Bad Data In File`＝エラーコード 58）。
- アスキー形式（`SAVE ,A` で保存したもの）のファイルは、テープ・ディスクとも読み書きできます。
- 機械語ファイル（`SAVEM` / `LOADM`）は、本実装の `SAVEM` と `LOADM` が対になる形式です。

中間コード形式の保存物を本実装で使うには、次のどちらかで取り込みます。

1. リストを本実装で打ち直し、本実装の `SAVE` で保存し直す。
2. 保存したときの環境で `SAVE "名前",A` によりアスキー形式で保存し直してから読み込ませる。

本実装は、文字列リテラルから文字列変数への代入でも**文字列領域を消費します**。リテラルの合計が大きいプログラムでは `CLEAR n` で文字列領域を広げてください（既定 300 バイト）。
