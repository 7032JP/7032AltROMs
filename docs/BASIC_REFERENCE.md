# BASIC_REFERENCE — 7T-BASIC の予約語と F-BASIC との違い

7T-BASIC は、FM-7 向けの F-BASIC 文法書を元に、同じ BASIC が動作するように実装しています。ただし、いくつかの点で F-BASIC と違いがあります。本書では、使える予約語の書式と例、F-BASIC との違いや制約について記載しています。文法の基準は F-BASIC 文法書に記載された F-BASIC V3.0（ROM モード）です。

- 凡例: **○**＝対応。未対応の語は [第 10 章](#10-f-basic-にあり-7t-basic-で未サポートの予約語) にあります。「制約」欄は対応する範囲の注記です
- 書式表記: `[ ]` は省略可能、`{A|B}` はいずれか一方を表します

## 対応状況の要約

| 区分 | 内容 |
| --- | --- |
| **○ 対応** | 未サポートを除く残り。第 1〜9 章の各表にあります |
| **対象外（ROM モード 8 語＋ディスク専用 3 語）** | 本実装が扱わない機能に属する語です。プリンタ（`LLIST` / `LPRINT` / `LPOS` / `HARDC`）、バブルカセット（`BUBINI` / `BUBW` / `BUBR`）、モニタ（`MON`）、ディスクの管理（`NAME` / `DSKINI` / `DSKF`） |
| **未対応（ROM モード 10 語）** | 上記以外の未サポートの語です。[第 10 章](#10-f-basic-にあり-7t-basic-で未サポートの予約語) の一覧 |

この集計は予約語ごとに、F-BASIC 文法書どおりの働きをするかどうかで数えています。ROM モードの対象は文法書 2.5.4 の V3.0／R 欄で予約語とされる 146 語で、ディスク専用の 3 語は補足です。○ の語の書式や挙動の細かな制約は、第 1〜9 章の各項に「制約」として書いてあります。機能ごとの対応状況（画面・入出力・グラフィック・サウンド等）は [COMPATIBILITY.md](COMPATIBILITY.md) §1.2 にあります。

## 1. 基本要素

### 1.1 行番号と直接モード

行番号（0〜63999 の整数）で始まる入力はプログラムとして格納され、行番号のないコマンド・ステートメントは直接モードで即時実行されます。63999 を超える行番号は `Syntax Error` になります。

1 行（論理行）は行番号を含めて **255 文字**まで入力できます。画面の右端を超えた分は次の表示行へ折り返して編集を続けられます。256 文字目以降の入力は受け付けず、格納される内容は先頭 255 文字です。

**キーワードの省略形**: 次の 16 語は「綴りの頭＋`.`」の省略形でも入力できます。プログラム行・直接モードのどちらでも受け付け、`LIST` は常に完全形で表示します（格納される内容も完全形です）。

| 完全形 | 省略形 | 完全形 | 省略形 | 完全形 | 省略形 | 完全形 | 省略形 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `CONT` | `C.` | `MERGE` | `ME.` | `RANDOMIZE` | `RNDM.` | `RUN` | `R.` |
| `LOAD` | `LO.` | `GOTO` | `GO.` | `LOCATE` | `LOC.` | `LIST` | `L.` |
| `SAVE` | `SA.` | `GOSUB` | `GOS.` | `COLOR` | `COL.` | `CONSOLE` | `CONS.` |
| `SKIPF` | `SK.` | `RETURN` | `RET.` | `MOTOR` | `M.` | `WIDTH` | `W.` |

省略形として扱うのは語として書いた場合だけです。引用符で囲んだ中、`REM` と `'` の後、`DATA` の並びは入力したままの文字が残ります。完全形にすると 255 文字を超える行では、その語は入力したままになります。

プログラム行の編集:

- 既存と同じ行番号で入力すると、その行を**置換**します。
- **行番号のみ**を入力すると、その行を**削除**します（該当行がない場合は何もしません）。
- 行番号の順に関係なく入力でき、常に**行番号昇順**の位置へ挿入されます（`LIST`／`RUN` は昇順）。
- プログラム行を入力（挿入・置換・削除のいずれか）すると、**変数はすべて消去**されます。

直接モードで入力した行を実行し終えると `Ready` を表示します。`:` で繋いだ複数の文は、その行をすべて実行し終えてから `Ready` を 1 回だけ表示します。行番号付きのプログラム行を入力したときは `Ready` を表示しません。

`Ready` は、**現在の行を閉じたうえで 1 行空けてから**表示します。末尾に `;` を付けた `PRINT` の直後でも、直前の出力と同じ行には混ざりません。実行時エラーの表示と `LIST` の一覧も、直前に 1 行空けてから表示します。`STOP` と中断キーの `Break` 表示は、現在の行を閉じる改行と空行を常に出すので、カーソルが行頭にあるときは空行が 2 行になります。

```
CLEAR

Ready
A=7

Ready
PRINT A
 7

Ready
```

### 1.2 変数

- 変数名は英字で始まる英数字列です。**先頭 16 文字が有意**で、17 文字目以降は区別しません。`COUNTERVALUEXYZ1A` と `COUNTERVALUEXYZ1B` は同じ変数で、16 文字目が違う `COUNTERVALUEXYZ2` は別の変数です。型宣言子（`%` `!` `#` `$`）が異なる同名の変数は別の変数です。
- **名前の途中に予約語の綴りが現れても、名前はそこで切れません**。`SCORES`／`ABCDEF`／`ATOB` はどれも 1 つの変数名です。名前は英数字以外の文字（空白・型宣言子・演算子・区切り記号）で終わり、そこから先は予約語として解釈します。`A OR B`・`A%OR2`・`6OR3`・`C ANDNOT1` の `OR` `AND` `NOT` はいずれも演算子です。
  - **名前の先頭に予約語の綴りがあると、そこは予約語として解釈します**。`TOTAL`（`TO`）・`ORDER`（`OR`）・`LENGTH`（`LEN`）は変数名として使えず、`Syntax Error` になります。
- 型宣言子: `%`＝整数（16 ビット）、`!`＝単精度、`#`＝倍精度、`$`＝文字列。無指定は単精度です。
- `DEFINT`／`DEFSNG`／`DEFDBL`／`DEFSTR` で、型宣言子を省略した変数の既定型を英字ごとに変更できます。単文字 (`DEFINT A`)、範囲 (`DEFINT A-Y`)、コンマ区切り (`DEFSTR A,C-F`) を指定できます。
- 配列は `DIM` で宣言します（[3.9](#39-dim) 参照）。文字列配列も使用できます。

### 1.3 定数

- 10 進整数（例 `123`、`-5`）、小数（例 `1.5`、`.333`）、指数形式（例 `1E6`、`2.5E-3`）。
- 16 進定数 `&H`（例 `&H6000`）、8 進定数 `&O` または `&`（例 `&O777`）。いずれも 16 ビットに収まる値までで、桁があふれる綴り（`&HFFFFF` など）は `Overflow`（エラーコード 6）になります。値は**符号なし**で、`&H8000` は 32768、`&HFFFF` は 65535 です。32767 を超える値は実数として持つので、`A%=&HFFFF` は `Overflow` になります。
- 文字列定数は `"..."`。
- 数値定数の精度: 有効桁が 7 桁以下なら単精度、8 桁以上なら倍精度です（`12345678` や `3.14159265` は倍精度）。接尾辞 `#` と `D` 指数（例 `1D-2`）は倍精度を、接尾辞 `!` と `E` 指数は単精度を指定します。

### 1.4 数値の表示形式

整数はそのまま、単精度は有効 6 桁、倍精度は有効 16 桁で表示します。絶対値が大きい値・小さい値は指数形式で表示します。単精度は `E` 形式（例 `1E+30`、`1E-04`）、倍精度は `D` 形式（例 `1D+17`）です。倍精度の四則演算と比較は 16 桁精度で行い、単精度・整数との混在は倍精度へ昇格します（例 `PRINT 1/3#` → `.3333333333333333`）。

**SAVE の保存形式と保証範囲**

- **形式** — 常にアスキー形式で、`,A` を指定しても同じです。`LIST` と同じ行番号つき本文（各行は復帰 `$0D` 終端）に続けて終端 `$1A` を置きます。
- **`,P`（保護保存）** — このオプションと保護されたプログラムの扱いは、互換性の保証対象外です。保護されたファイルを扱う用途では使用しないでください。
- **媒体上の属性** — テープのヘッダブロック（ファイル名・ファイル形式・属性）とディスクのディレクトリスロット（ファイルタイプ・アスキーフラグ）を用います。アスキー形式の BASIC ソースはファイル形式 `00`、属性 `$FF` です。テープのブロックの種別は `00` ヘッダ / `01` データ / `FF` エンドです。

ディスクは、プログラムの読込（`LOAD`）・保存（`SAVE`）・機械語の読込（`LOADM`）・ディレクトリ一覧（`FILES`）・ディスク起動に対応します。ディレクトリと割当表の空きが足りないときは `Directory Full` ／ `Disk Full` になります。ディスク上のファイルを `OPEN` で開く入出力は未対応で、ディスクを指すデバイス記述子の `OPEN` は `Device Unavailable`（エラーコード 60）です（§4.8）。ディスクの `LOAD`・`LOADM`・`SAVE`・`FILES` を実行するとバックグラウンド演奏は停止します。ディスク入出力とバックグラウンド演奏の同時実行には対応していません。

同じ名前のファイルが既にあるディスクへ `SAVE` すると、直接モードでは `Are you sure (Y or N)` と問い合わせます。`Y` を打つと元のファイルを消して保存し、`N` を打つと保存しません。プログラムの中の `SAVE` では問い合わせず、`File Already Exists In 行番号` になります。

## 3. プログラム制御ステートメント

### 3.1 LET（代入）

```
[LET] 変数 = 式
```
例: `LET A=10` ／ `B$="ABC"`（LET は省略可能）

### 3.2 FOR〜NEXT／STEP／TO

```
FOR 変数 = 初期値 TO 終値 [STEP 増分]
  ...
NEXT [変数[,変数...]]
```
例: `FOR I=3 TO 1 STEP -1 : PRINT I; : NEXT` ／ `FOR X=0 TO 1 STEP 0.5`

- 整数・実数の制御変数、負・小数の STEP に対応します。
- 同じ制御変数で `FOR` を再実行すると、以前のループ（とその内側のループ）は破棄され、新しいループに入ります。
- **制約**: `NEXT` の変数名は段数の消化にのみ使い、名前の照合は行いません。

### 3.3 GOTO／GOSUB／RETURN

```
GOTO 行番号  ／  GOSUB 行番号  ／  RETURN [行番号]
```

例: `GOSUB 1000` … `1000 PRINT "SUB" : RETURN`

- `GO TO` ／ `GO SUB` の分かち書きも受理します。`ON 式 GO TO ...` も同様です。
- `RETURN` に行番号を書くと、`GOSUB` の直後の文ではなくその行へ復帰します。無い行番号は `Undefined Line Number` です。
- **直接モードでの `GOTO`**: 指定行へ制御を移し、そこから**プログラムの実行を続けます**。変数は消去しません。プログラムの終わりまで走り切ると直接モードへ戻り、同じ入力行に `:` で繋いだ後続の文は実行しません。
- **直接モードでの `GOSUB`**: サブルーチンを実行し、`RETURN` で**入力行の残りの文へ戻って続きを実行**します。`GOSUB 1000:PRINT "END"` は、サブルーチンから戻ったあとに `END` を表示します。`RETURN` に出会わないままプログラムの終わりまで走り切ると、入力行の残りを実行せずに直接モードへ戻ります。
- 直接モードの `GOSUB` の途中で `STOP` に出会った場合、`CONT` で再開すると `RETURN` を経て入力行の残りの文まで続きます。
- `IF 式 THEN 行番号` ／ `ON 式 GOTO`／`ON 式 GOSUB` を直接モードで使ったときも、上と同じ規則で動きます。

### 3.4 IF〜THEN〜ELSE

```
IF 式 THEN 文[:文...] [ELSE 文[:文...]]
IF 式 GOTO 行番号
```
例: `IF N=1 THEN PRINT "YES" ELSE PRINT "NO"` ／ `IF N=1 GOTO 100` ／ `IF N=1 THEN GOTO 100`

- `THEN`・`ELSE` の直後は、文でも行番号だけ（`THEN 100`／`ELSE 200`）でも記述でき、いずれもその行へ分岐します。

### 3.5 ON〜GOTO／ON〜GOSUB／ON ERROR GOTO

```
ON 式 GOTO 行番号[,行番号...]
ON 式 GOSUB 行番号[,行番号...]
ON ERROR GOTO 行番号        （0 指定でトラップ解除）
```
例: `ON N GOTO 100,200,300`

- `ON INTERVAL GOSUB 行番号` は割込み先の行を登録します。存在しない行番号は `Undefined Line Number` です。`INTERVAL 数式` で設定した間隔（秒）が経過するたびに、文の切れ目で登録行へ GOSUB として入り、`RETURN` で中断した文へ戻ります（→ 4.5 INTERVAL）。`ON INTERVAL GOTO` は `Syntax Error` です。
- `ON KEY(番号) GOSUB 行番号` は機能キー割込みの飛び先を登録します。番号は 1〜10 で、範囲外は `Illegal Function Call`、存在しない行番号は `Undefined Line Number` です。登録したキーは `KEY(番号) ON` で割込みを許可してから使います（→ [4.3](#43-key)）。`ON KEY(n) GOTO` は `Syntax Error` です。
- `ON TIME GOSUB 行番号` はタイマ割込みの飛び先を登録します（`ON TIME$ GOSUB` と綴っても同じです）。存在しない行番号は `Undefined Line Number` です。`TIME "hh:mm:ss"` で決めた割込予約時刻に達すると、文の切れ目で登録行へ GOSUB として入り、`RETURN` で中断した文へ、`RETURN 行番号` ならその行へ戻ります（→ 4.6 TIME）。`ON TIME GOTO` は `Syntax Error` です。
- **制約**: `ON COM GOSUB` の形には対応していません。
- `ON ERROR GOTO 0` はエラートラップを解除します。以後に発生したエラーは通常どおりエラーメッセージを表示してプログラムを止めます。
- **エラー処理へ入っている間に実行した場合**:
  - `ON ERROR GOTO 0` … トラップを解除し、**その場でプログラムを止めて、エラー処理へ飛ぶきっかけになったエラーを表示します**。表示する発生行番号もそのエラーが起きた行です。
  - `ON ERROR GOTO 行番号` … 分岐先の行番号だけを差し替えます。エラー処理へ入っている間はトラップが止まったままで、`RESUME` を通ったときに新しい行番号で再開します。したがってエラー処理の途中で起きたエラーは捕捉されず、そのまま表示されます。

### 3.6 ERROR／RESUME

```
ERROR エラーコード      （エラーを発生させる）
RESUME [0 | NEXT | 行番号]
```
例: `10 ON ERROR GOTO 100` … `100 RESUME NEXT`

- 飛び先のルーチンでは `ERR`（発生したエラーのコード）・`ERL`（エラーが発生した行番号）を参照できます。例: `100 PRINT ERR : PRINT ERL`
- **`RESUME`（引数なし）／`RESUME 0` の再開位置**は、エラーが起きた**文の先頭**です。文の切れ目は行の先頭と `:` で、`IF 〜 THEN 〜` / `ELSE 〜` の節へ入るところは切れ目に数えません。`30 IF D=0 THEN X=1/Z` でエラーが起きたときは **`IF` の条件判定からやり直します**。`30 A=A+1:B=1/Z` では `:` の直後（`B=1/Z`）からやり直します。
- **`ERR` は `RESUME` を通ると 0 に戻ります**。`RESUME` / `RESUME NEXT` / `RESUME 行番号` のいずれも同じです。エラー処理ルーチンが `RESUME` を通らずに終わった場合や、トラップしていないエラーで止まった場合は値が残ります。**`ERL` は `RESUME` では戻らず**、最後にエラーが起きた行番号を保ちます。
- エラーコードと表示されるメッセージの一覧は [9. 実行時エラーの表示とエラーコード](#9-実行時エラーの表示とエラーコード) にあります。

### 3.7 WHILE〜WEND

```
WHILE 式 ... WEND
```
例: `I=0:WHILE I<3:I=I+1:WEND:PRINT I` → ` 3`

### 3.8 END／STOP／REM／'

- `END`: プログラムを終了します。停止した位置は記録され、`CONT` で `END` の次の文から再開できます。
- `STOP`: `Break In <行番号>` を表示して中断します。`CONT` で**停止した文の次の文**から再開できます。直接モード（行番号を付けずに打ち込んだ `STOP`）は発生行が無いので `Break` だけを表示し、記録済みの再開位置も書き換えません。
- **中断キー**: 走行中のプログラムは中断キー（Break）で止められます。文の切れ目で受け付け、`Break In <行番号>` を表示して直接モードへ戻ります。直接モードで打ち込んだ実行を止めたときは `Break` だけを表示します。
- **中断できる場面**: `INPUT` の入力待ちは CTRL+C / CTRL+X で中断できます（打ちかけの文字は捨てられます）。中断キー（Break）は入力待ちの間は効かず、[RETURN] で入力を終えた後の文の切れ目で受け付けます。カセットの読取待ちでは中断キーが効きます（カセットのモーターも止まります）。`Ready` の行入力中は、CTRL+C / CTRL+X で打ちかけの行を捨てて入力し直せます。
- 中断キーで止めた後の `CONT`: 止めた文の先頭から実行を再開します。`INPUT` の入力待ちで止めた場合はその `INPUT` 文を初めからやり直し、捕捉されなかった実行時エラーで停止した場合はそのエラーが起きた文をやり直します。変数の値は引き継ぎ、中断中に直接モードで代入した値も反映します。`FOR` / `GOSUB` / `WHILE` の入れ子は BREAK・STOP・END の後は保ちますが、捕捉されなかった実行時エラーの後は破棄します。
- **再開できなくなる操作**: `NEW` ／ `CLEAR` ／ 行の追加・置換・削除を行った後は `Can't Continue` になります。`LIST` や直接モードの `PRINT`・代入は再開位置に影響しません。プログラムが最後まで走り切った後の `CONT` は、エラーにならず何もしません。
- `REM` および `'`: 注釈。行末まで無視されます。本文の英字の大小は打ち込んだまま残り、`LIST` にもそのまま出ます。

### 3.9 DIM

```
DIM 変数名(上限[,上限...])[,...]
```
例: `DIM P(20)` ／ `DIM NM$(4,4)`

- 多次元配列に対応し、7T-BASIC の次元数の上限は **44 次元**です。確保できる要素数は、利用可能なメモリの量に制限されます。

### 3.10 READ／DATA／RESTORE

```
READ 変数[,変数...]  ／  DATA 定数[,定数...]  ／  RESTORE [行番号]
```
例: `READ A,B$ : DATA 7,HI`

- `DATA` の値はコンマで区切ります。値は文の区切り (`:`) か行末でも終わります。
- 引用符で囲まない値は、前後に付いた空白を取り除いてから渡します（値の途中の空白はそのまま残ります）。`DATA CD   ,  EF` から読める値は `CD` と `EF` です。
- 引用符で囲まない値は、英字の大小も打ち込んだままで渡します（`DATA abc,Def` から読める値は `abc` と `Def` です）。
- 引用符で囲んだ値は、引用符が区切り記号として働き、中身がそのまま値になります。前後に空白を含む値やコンマを含む値は、この形でだけ 1 個の値として書けます。
- `DATA` 文は文の区切り (`:`) で終わるので、同じ行に続けて書いた文は実行されます（`10 DATA 1,2 : PRINT "OK"` は `OK` を表示します）。引用符で囲んだ値の中の `:` は値の一部で、区切りにはなりません。
- 数値変数へ読む値は、**空の値**も**数として読めない綴り**も `Syntax Error` になります。空の値とは `DATA 1,,3` の 2 個目のように値が 1 文字も無いもの、数として読めない綴りとは `12X` のように数の後ろに字が残るものです。誤りの発生行は `READ` を書いた行ではなく、**その値を持つ `DATA` の行**として表示されます。`ON ERROR GOTO` で捕まえたときの `ERL` も同じです。
- 文字列変数へ読む値は、空でも長さ 0 の文字列として正しく受け取ります。

### 3.11 DEF USR／USR

```
DEF USR[n] = アドレス      （n=0〜9、省略時 0）
変数 = USR[n](引数)
```
例: `DEF USR0=&H6000 : A=USR0(5)`

- 機械語ルーチンのエントリポイントでは **A = 引数の型（2 = 整数、3 = 文字、4 = 単精度実数、8 = 倍精度実数）**、**X = 引数の値が格納されているアドレス**です（F-BASIC 文法書 3.2 DEF USR）。16 ビット整数の引数は `2,X`〜`3,X` にあり、ルーチンが `2,X` へ書いた値が関数の戻り値になります（書かなければ引数がそのまま返ります）。文字列の引数では X が 3 バイトの記述子（長さ 1 バイト、文字列のアドレス 2 バイト）を指します。実数の引数では X が本実装の浮動小数アキュムレータを指します。
- 未定義の USR 呼び出しは `Illegal Function Call`（コード 5）になります。

### 3.12 DEF FN／FN

```
DEF FN名前(仮引数) = 式
変数 = FN名前(実引数)
```
例:
```basic
10 DEF FNA(X)=X*X+1
20 PRINT FNA(3)
RUN
```
→ ` 10`

- `DEF FN` はプログラムの中で定義します。直接モードでは `Illegal Direct`（コード 12）になります。
- 再定義・複数定義・式内での複数使用に対応します。
- FN の入れ子（定義式や実引数の中で別の FN を呼ぶこと）にも対応します。プログラム中で `DEF FNA(X)=X*2`、`DEF FNB(X)=FNA(X)+X` の順に定義した後、`PRINT FNB(3)` は ` 9` を表示します。同名の仮引数を使っても、呼び出しの前後で変数の値は変わりません。

### 3.13 POKE／PEEK

```
POKE アドレス,値      ／      変数 = PEEK(アドレス)
```
例: `POKE &H6000,65 : PRINT PEEK(&H6000)`

- アドレスは 0〜65535、`POKE` の値は 0〜255 です。範囲外は `Illegal Function Call`（エラーコード 5）になります。

### 3.14 CHAIN

```
CHAIN "ファイル名"
```
- **制約**: `RUN "ファイル名"` と同義です。変数の引き継ぎ、`MERGE`／`ALL`／行番号指定には対応していません。

### 3.15 ERASE

```
ERASE 配列名[,配列名...]
```
例: `DIM Z(3) : Z(1)=4 : ERASE Z : DIM Z(5)`

- 指定した配列を消去します。消去後は同じ名前を別の大きさで `DIM` し直せます。
- 存在しない配列名を指定しても何も起こりません（エラーになりません）。

### 3.16 DEFINT／DEFSNG／DEFDBL／DEFSTR

```
{DEFINT | DEFSNG | DEFDBL | DEFSTR} 文字の範囲[,文字の範囲...]
```
例: `DEFINT A,C,E` ／ `DEFSNG B-X` ／ `DEFDBL D-G` ／ `DEFSTR A,E-G`

- 指定した英字で始まる**すべての変数名**について、型宣言子を省略したときの既定の型を、整数／単精度／倍精度／文字に宣言します。
- 文字の範囲は 1 字の英字、または `英字-英字` です。後者は範囲の左側の英字が右側の英字よりアルファベット順で前でなければならず、逆順に書くと `Syntax Error` になります。コンマで複数並べられます。
- **型宣言子（`%` `!` `#` `$`）は型宣言文よりも優先します。** `DEFINT A-Z` のあとでも `A!` は単精度、`A$` は文字列です。
- 型宣言文も型宣言子も伴わない変数は単精度として扱われます。
- 宣言は単純変数にも配列にも及びます。
- 変数をすべて消去する操作（`RUN` ／ `NEW` ／ `CLEAR` ／ プログラム行の入力）で、宣言も既定（単精度）へ戻ります。

例:
```basic
10 DEFINT A,C,E
20 A=12.5:C=3.4:E=7.6
30 PRINT A;C;E
```
→ ` 13  3  8`

### 3.17 SWAP

```
SWAP 変数,変数
```
例: `SWAP A,B` ／ `SWAP A$,B$` ／ `SWAP Q(1),Q(2)`

- 2 つの変数の値を交換します。整数・単精度・倍精度・文字のいずれの型でも交換でき、単純変数のほか配列要素も指定できます。
- **2 つの変数の型は同じでなければなりません。** 一致しない場合は `Type Mismatch`（エラーコード 13）になります（`SWAP A,B$` や `SWAP A%,B` は誤りです）。
- 交換で型と精度は変わりません。文字変数の交換は記述子だけを入れ換えるので、文字列の実体を複写したり作り直したりはしません。
- **制約**: 未定義の単純変数を書いてもエラーにせず、その変数を初期値（数値は 0、文字列は長さ 0）で作ってから交換します。

例:
```basic
10 A=1.25:B=2.5
20 SWAP A,B
30 PRINT A;B
```
→ ` 2.5  1.25`

### 3.18 RENUM

```
RENUM [新行番号][,[旧行番号][,増分値]]
```
例: `RENUM` ／ `RENUM 100,,10` ／ `RENUM 30,50,20` ／ `RENUM ,20,10`

- プログラムの各行の行番号を付け直します。
- 新行番号は新しく付ける行番号の最初の番号です。省略値は 10 です。
- 旧行番号は新しく付け始める、現在のプログラムの中の行番号です。省略値はプログラムの最初の行番号です。
- 増分値は新しく付ける行番号の増分値です。省略値は 10 です。
- `GOTO` ／ `GOSUB` ／ `THEN` ／ `ON 〜 GOTO` ／ `ON 〜 GOSUB` ／ `ERL` とともに参照している行番号も併せて付け直します。`REM` ／ `'` の注釈と `DATA` の値は本文のままで、付け直しの対象にしません。
- 参照先がプログラム中に無い行番号は `Undefined Line Number <旧行番号> In <その文の新しい行番号>` を表示し、その行番号はそのまま残します。
- 63999 を超える行番号を発生させる指定と、プログラムの順序が変わる指定は `Illegal Function Call` になります。
- 実行すると直接モードへ戻ります。プログラムの途中に書いた `RENUM` は、付け直しを終えた時点で実行を打ち切ります。
- **`RENUM` はすべての変数を消去し、`CONT` の再開位置も無効にします**。行の挿入・削除と同じ扱いです。

## 4. 画面・入出力ステートメント

### 4.1 PRINT

```
PRINT [式][{;|,}式...]
```
例: `PRINT "SUM:";S` ／ `PRINT 1,2`（14 桁ゾーン区切り）

- 数値・文字列の混在、`;`（連続）・`,`（ゾーン）・行末 `;` による改行抑止に対応します。
- 行末までに収まらない項目は桁の途中で割らず、項目ごと次の行の先頭から表示します。1 行の桁数を超える長い項目だけは、その場から折り返します。
- `TAB(n)`（桁位置合わせ）・`SPC(n)`（空白 n 個）・`USING`（書式出力、下記）に対応します。`TAB` の桁位置は 0〜32767、`SPC` の個数は 0〜255 です。
- 1 つの PRINT 文に関数呼び出しを複数並べられます（例: `PRINT ABS(-5);SQR(4)` → ` 5  2`）。
- `PRINT` の代わりに `?` と書けます（`?1+1` ／ `10 ?A,B` ／ `IF A THEN ?"Y"`）。`LIST` は打ち込んだとおりに `?` を出します。

#### PRINT USING（書式出力）

```
PRINT USING "書式";式[{;|,}式...]
```
例: `PRINT USING "###.##";3.14159` → `  3.14` ／ `PRINT USING "& &";"ABCDE"` → `ABC`

書式文字列（文字式も可）に従って値を整形出力します。書式は値が残っている限り繰り返し使われます。

- 数値の書式制御文字:
  - 桁を並べるもの … `#`（1 個で 1 桁。値は右詰めで、負号もこの桁を 1 つ使います）／`.`（小数点。小数側は指定した桁数へ丸め、足りない位は 0 で埋めます）／`,`（整数側を下位から 3 桁ずつ区切ります。区切り記号もそれぞれ 1 桁を使います）
  - 空きの埋め方を決めるもの … `**`（左の空きをアスタリスクで埋めます。2 桁分）／`¥¥`（数のすぐ左へ円記号を出します。2 桁分を取り、うち 1 桁を円記号が使います）／`**¥`（両方を兼ねます。3 桁分）
  - 符号の出し方を決めるもの … 先頭の `+`（`+` か `-` を数の直前へ）／末尾の `+`（数の後ろへ `+` か `-`）／末尾の `-`（負のときだけ数の後ろへ `-`）
  - 指数形式にするもの … `^^^^`（下記）
  - 桁が足りなかったとき … 用意した桁に収まらない値は、頭に `%` を付けたうえでそのまま出します
- 文字列の書式制御文字:
  - `!` … 幅 1。先頭の 1 文字だけを取り出します
  - `&` … 2 個の `&` が 1 つの欄を作ります。欄の幅は 2 個の `&` とその間に置いた空白の合計文字数で、値が短ければ右側を空白で埋めます
  - `@` … 幅の指定を行わず、値の全体を出します
- 書式制御文字に当たらない文字は、そのまま出力へ混ぜられます。`_` を書くと、その次の 1 文字は書式制御文字の役目を失い、ただの文字として出ます。
- **制約**: 数値の有効桁は PRINT と同じです（単精度は有効 6 桁）。
- **制約**: 数値フィールドの桁位置 `#` は 24 個までです。25 個以上を並べた書式は Illegal Function Call（エラーコード 5）になります。

指数形式 `^^^^` は、桁指定・小数指定の後（末尾の符号より前）に `^` をちょうど 4 個並べて指定します。

```
PRINT USING "##.##^^^^";6.4E9    →  6.40E+09
PRINT USING "####.#^^^^";6.4E9   →  640.0E+07
PRINT USING "##.##^^^^+";6.4E9   → 64.00E+08+
```

- 仮数部の整数部の桁数は、桁位置の数から符号ぶんの 1 桁を引いた数です。末尾に符号（`+`／`-`）を指定したときは、桁位置の数がそのまま整数部の桁数です。
- 指数部は `E`（単精度）または `D`（倍精度）に続けて符号と 2 桁で出力されます。値が 0 のときは指数も `+00` になります。
- 指数形式ではコンマ区切りは行われません（`,` は桁位置としては数えます）。
- `^` が 4 個そろわないときは指数形式にならず、`^` はそのまま出力されます。5 個目以降の `^` もそのまま出力されます。

### 4.2 CLS／LOCATE／WIDTH／COLOR／SCREEN

| 予約語 | 対応 | 書式 | 例 | 制約 |
|---|:---:|---|---|---|
| CLS | ○ | `CLS` | `CLS` | |
| LOCATE | ○ | `LOCATE X,Y[,S]` | `LOCATE 12,3` | X は 0〜(桁数-1)、Y は 0〜(行数-1)（`WIDTH 40,20` なら 0〜39 / 0〜19、`WIDTH 80,25` なら 0〜79 / 0〜24）、S はカーソル表示で 0（消す）か 1（表示）です。いずれも外れると `Illegal Function Call` になります。X・Y は省略できません。引数の位置に `,` を置いた書き方（`LOCATE ,5` ／ `LOCATE 5,,0` ／ `LOCATE ,,1` 等）は Syntax Error、引数の位置で文が尽きた書き方（`LOCATE` ／ `LOCATE 5,` ／ `LOCATE 5,5,`）は Missing Operand になります。誤りになった LOCATE は画面へ一切作用しません（カーソルも動きません） |
| WIDTH | ○ | `WIDTH [{40\|80}][,{25\|20}]` | `WIDTH 80` | 範囲外の値はエラーになります。行数を省いたときは**現在の行数を保ちます**（桁数だけが変わります）。桁数を省いた `WIDTH ,20` は現在の桁数のまま行数を 20 にし、同時に `CONSOLE 0,20,0,0` を実行します。起動直後は 40 桁 × 20 行です |
| CONSOLE | ○ | `CONSOLE [開始行][,行数][,機能キー行][,単色表示]` | `CONSOLE 16,4` | テキスト描画のスクロール領域（第 1・第 2 引数）、機能キー行の表示（第 3 引数）、単色表示（第 4 引数）に対応しています。引数ごとの動作は表の下にあります |
| COLOR | ○ | `COLOR [前景][,背景]` ／ `COLOR = (パレット,カラー)` | `COLOR 7` ／ `COLOR=(1,4)` | 前景色・背景色の指定と、パレットへのカラーコードの割付けに対応します。`COLOR = (0,カラー)` は値を受理し、0 番のパレット（画面の地）は黒（色 0）のままです。パレット 0 に黒以外の色を割り付けることはできない、という F-BASIC 文法書の規定どおりの動作です |
| SCREEN | ○ | `SCREEN [<書き込み面>][,<表示面>]` | `SCREEN 1,1` ／ `SCREEN ,7` | 引数は重ね合わせ表示の 3 面に対応する 3 ビットのマスク（0〜7、1 = 選択）。省略した側は現在の指定を保ちます |

**CONSOLE 文**（スクロール領域・機能キー行・単色表示）

- **スクロール領域（第 1・第 2 引数）** — 指定すると画面を消してカーソルを領域の左上へ置き、以後の表示は領域の中だけに出ます。領域の最下行から出るときは領域の中だけが 1 行スクロールし、領域の外は動きません。行の数え方は現在の行数（20 行なら 1 行 10 ライン、25 行なら 8 ライン）に従います。
- **引数の範囲** — 開始行は 0〜(行数-1)、行数は 0〜現在の行数、開始行＋行数は現在の行数以内で、外れると `Illegal Function Call` です。
- **省略した引数**は現在の設定を保ちます。`CONSOLE 16,4` の後の `CONSOLE 10` は行数 4 のまま開始行だけを 10 へ、`CONSOLE ,8` は開始行 16 のまま行数だけを 8 へ変えます。引数をすべて省いた `CONSOLE` は領域を変えずに画面を消し、カーソルを領域の左上へ戻します。`WIDTH` は領域を画面全体へ戻します。
- **機能キー行（第 3 引数）** — 1 にすると画面の下 2 行に機能キーの内容を表示し、スクロール領域に使える行が 2 行減ります。上の行に 1〜5、下の行に 6〜10 を置き、1 個の欄は桁数の 1/5 で、内容は欄の左端から欄の幅まで表示します。`KEY` で内容を変えると表示も変わり、`CLS` の後も表示を保ちます。0 にすると表示せず、使える行は元に戻ります。
- **単色表示（第 4 引数）** — 1 にすると `PRINT` 等の文字を緑のみで表示します。`COLOR` の指定は保たれ、0 に戻すとその色で表示します。図形の色と `PUT@` の属性色は変わりません。
- `LOCATE` の行は領域に関係なく画面の絶対行です。

**SCREEN 文**（重ね合わせ表示の面の選択）

```
SCREEN [<書き込み面マスク>][,<表示面マスク>]
```
- 第 1 引数は以後の描画・文字出力を書き込む面、第 2 引数は画面に映す面です。いずれも 0〜7 の 3 ビットのマスクで、ビットが 3 つの面に 1 対 1 で対応します（1 = 選択）。
- 書き込み面を 0 にすると以後の出力はどの面にも書かれません。表示面を 0 にすると画面が真っ暗になります。どちらも指定し直せば元に戻ります。
- 省略した側は現在の指定を保ちます。`SCREEN` 単独・`SCREEN ,` も受理し、何も変えません。
- 指定は `CLS` `RUN` `NEW` をまたいで保たれます。起動時は書き込み面・表示面とも 7（全面）です。
- 0〜7 の外は `Illegal Function Call`、文字列は `Type Mismatch`、引数 3 個以上は `Syntax Error` になります。エラーのときは面の指定を変えません。小数を与えたときは最近接へ丸めるので、`-0.4` は 0 になり、`-0.5` と `-0.6` は `Illegal Function Call` です。
- 式の中で使う関数形 `SCREEN(X,Y[,SW])` は別の機能です（[7.1](#71-数値関数)）。
- 面を分けて描いてから表示面だけを切り替えると、書き上がる途中を見せずに絵を差し替えられます。

### 4.3 KEY

```
KEY 番号,"文字列"      （番号=1〜10）
KEY LIST
KEY(番号) {ON | OFF | STOP}      （番号=1〜10）
```
- `KEY 番号,"文字列"` の形は機能キーへ文字列を割り当てます。
- `KEY 番号,""`（空文字列）はそのキーの割り当てを消します。消したキーは一覧で空欄になり、押しても何も入力されません。空白 1 文字の割り当て（`KEY 番号," "`）とは別物です。
- `KEY LIST` は PF1〜PF10 の割り当て内容を 1 行 1 キーで一覧表示します。`PF<番号>` に続けて桁 9 から割り当て文字列を出し、割り当てのないキーは `PF<番号>` だけの行になります。
- `KEY ON`／`KEY OFF`（丸括弧の番号を伴わない形）は `Syntax Error` になります。

#### KEY(番号) ON ／ OFF ／ STOP（機能キー割込み）

- `ON KEY(番号) GOSUB 行番号`（→ [3.5](#35-ongotoongosubon-error-goto)）で登録した飛び先への分岐を、許可・禁止・保留します。番号は 1〜10 で、範囲外は `Illegal Function Call` になります。引数の後に続けられるのは文の区切り（`:` または行末）だけです。
- `KEY(n) ON` は割込みを許可し、分岐も行います。`KEY(n) OFF` は割込みを禁止し、まだ分岐していない発生分も捨てます。`KEY(n) STOP` は受付だけを続けて分岐を止め、止めている間の発生は次の `KEY(n) ON` の後に分岐します。
- 分岐は**文の切れ目と行の飛び先**で行い、`RETURN` で中断した文へ戻ります。保留は 1 件だけ持ち、続けて押した分は最後の 1 件に畳まれます。
- 割込みルーチンの実行中は自動的に保留になり、`RETURN` で解除されます。割込みは入れ子になりません。この保留は `INTERVAL` の割込みと共通で、どちらかのルーチンを実行している間はもう一方も分岐しません。
- 飛び先を登録していないキーを許可した場合、そのキーの発生は分岐せずに捨てられます。

### 4.4 INKEY$

```
変数$ = INKEY$
```
例: `10 K$=INKEY$ : IF K$="" GOTO 10` … `20 PRINT ASC(K$)`

- 押されたキー 1 文字を返します。まだ何も押されていなければ長さ 0 の文字列になります。

### 4.5 INTERVAL

```
INTERVAL 数式   ／  INTERVAL ON  ／  INTERVAL OFF  ／  INTERVAL STOP
```
例: `INTERVAL 10` ／ `INTERVAL ON`

- 引数は上の 4 つの形のいずれか 1 つだけです。引数の後に続けて書けるのは文の区切り（`:` または行末）だけで、`INTERVAL ON,10` や `INTERVAL=10`、`INTERVAL 10,20` は `Syntax Error` になります。引数を省いた `INTERVAL` は `Missing Operand` です。
- `INTERVAL 数式` は割込みの間隔を **秒** で設定します。数値は小数部を 0 に近づく方向へ切り捨てた値が 1〜65535 の場合だけ受け付けます。0（`0.9` など、0 へ切り捨てられる小数を含む）・負数・65536 以上は `Illegal Function Call` です。`INTERVAL ON` で許可すると、間隔が経過するたびに `ON INTERVAL GOSUB` の登録行が呼ばれます。禁止（OFF）状態からの許可は計数を最初からやり直します。
- `INTERVAL OFF` は割込みを禁止し、まだ処理していない間隔満了も捨てます。`INTERVAL STOP` は登録行の呼び出しだけを保留し、保留中の間隔満了 1 件は次の `INTERVAL ON` の直後に呼び出されます。
- 割込みルーチンの実行中は自動的に保留になり、`RETURN` で解除されます。割込みは入れ子になりません。登録行が呼ばれるのはプログラム実行中だけで、直接モードでは呼ばれません。間隔を設定しないまま `INTERVAL ON` にしても割込みは発生しません。

### 4.6 TIME

```
TIME "hh:mm:ss"   ／  TIME ON  ／  TIME OFF  ／  TIME STOP
```
例: `TIME "07:30:00"` ／ `TIME ON`

- `TIME "hh:mm:ss"` はタイマ割込みを起こす時刻（割込予約時刻）を決めます。設定できるのは 1 つだけで、2 つの時刻を同時には持てません。書式が `hh:mm:ss` でない、または時が 24 以上・分秒が 60 以上のときは `Illegal Function Call` です。時計そのものを合わせるのは `TIME$="HH:MM:SS"` です（`=` の有無で別の文になります）。
- `TIME ON` で許可すると、時計が割込予約時刻に達したところで、文の切れ目で `ON TIME GOSUB` の登録行へ GOSUB として入ります。`RETURN` で中断した文へ、`RETURN 行番号` ならその行から再開します。
- `TIME OFF` は割込みを禁止し、まだ処理していない発生も捨てます。`TIME STOP` は登録行の呼び出しだけを保留し、保留した発生は次の `TIME ON` の直後に呼び出されます。
- 割込みルーチンの実行中は自動的に保留になり、`RETURN` で解除されます。割込みは入れ子になりません。登録行が呼ばれるのはプログラム実行中だけで、直接モードでは呼ばれません。

### 4.7 INPUT

```
INPUT [ "プロンプト" {;|,} ] 変数[,変数...]
```
例: `INPUT X` ／ `INPUT "NAME";N$` ／ `INPUT "N",X` ／ `INPUT X,Y`

- キーボードから 1 行を読み取り、変数へ格納します。数値変数・文字列変数のどちらにも使えます。
- プロンプトを省略すると `?` を表示します。`;` で区切ると「プロンプト＋`?` 」を、`,` で区切るとプロンプトのみを表示して入力を待ちます。
- 変数を複数指定したときは、入力側もコンマで区切って与えます（例: `3,4`）。区切りには `:` も使え、コンマと同じ働きをします（`INPUT X,Y` へ `12:34` と打つと 12 と 34 が入ります）。
- 打ち込んだ項目は、コンマの前後に付いた空白を取り除いてから変数へ入れます（項目の途中の空白はそのまま残ります）。`AB  ,  CD` と打つと `AB` と `CD` が入ります。
- 項目を引用符で囲むと、引用符は区切り記号として扱われて値には入らず、中身がそのまま値になります。前後に空白を含む値やコンマを含む値は、この形でだけ 1 項目として渡せます（例: `"XY  "` は長さ 4、`"X,Y"` は 1 項目）。引用符の中の `:` も値の一部になります。
- 打ち込んだ内容が変数の並びと合わないときは `?Redo From Start` と表示して、同じ `INPUT` を最初からやり直します。合わないのは、項目が変数より少ない、項目が変数より多い、数値変数へ数として読めない項目（空の項目を含む）を打った、の 3 つの場合です。打ち直しの促しは誤りではないので `ON ERROR GOTO` では捕まらず、変数の値も書き換わりません。
- **制約**: ファイル入力の `INPUT #` は使えません。

#### LINE INPUT

```
LINE INPUT [;] [ "プロンプト"; ] 文字列変数
```
例: `LINE INPUT A$` ／ `LINE INPUT "NAME? ";N$`

- キーボードから 1 行を、コンマや引用符で区切らずそのまま 1 個の文字列変数へ読み込みます。
- `INPUT` と違い、プロンプトの後に `?` を自動では付けません。プロンプトを省略すると何も表示せずに入力を待ちます。
- 指定できる変数は文字列変数 1 個だけです。
- 1 行入力は行末に並ぶ空白を切り落としてから渡します。行頭・行中の空白はそのまま残ります。空白だけを打って確定した行は長さ 0 の文字列になります。この規則は `INPUT`・直接モードの入力・プログラム行の打ち込みにも同じように働きます。
- `LINE INPUT` は引用符を特別扱いしません。`"XY  "` と打てば引用符も含めた 6 文字がそのまま入ります。
- 行入力中の桁送りキー（TAB）は、次の桁位置まで空白を詰めます。桁位置は画面の 1・9・17… と 8 桁刻みで、既に桁位置に居るときは 1 つ先の桁位置まで送ります。詰めた空白は行の一部になり、行末に来た空白は上の規則で切り落とされます。

### 4.8 OPEN／CLOSE

```
OPEN "モード",[#]ファイル番号,"デバイス記述子"
CLOSE [[#]ファイル番号[,[#]ファイル番号...]]
```
例: `OPEN "O",#1,"SCRN:"` ／ `CLOSE #1` ／ `CLOSE`

- ファイル番号とデバイスを結び付けます。対応するデバイス記述子はキーボードの `KYBD:` と画面の `SCRN:` の 2 つで、どちらも入出力の緩衝を持ちません。
- ファイル番号は 1〜16 です。範囲の外を指定すると `Bad File Number`（エラーコード 50）です。
- 既に開いているファイル番号をもう一度開くと `File Already Open`（エラーコード 52）です。
- `KYBD:` と `SCRN:` は入出力の向きで働きが変わらないため、モードの文字列は `"I"` ／ `"O"` のどちらでも同じに受理します。
- 上記以外のデバイス記述子（カセット・ディスク・プリンタ・RS-232C・バブルカセット）は `Device Unavailable`（エラーコード 60）です。
- `CLOSE` はファイル番号を並べた分だけ閉じます。番号を省略すると開いている全てのファイルを閉じます。開いていないファイル番号を指定しても誤りにはなりません。
- `END` は開いている全てのファイルを閉じます。`STOP` は閉じません（`CONT` で続けられるようにするため）。
- **制約**: 開いたファイル番号に対する入出力（`PRINT #` ／ `INPUT #` ／ `EOF` ／ `LOF`）は未対応です。

### 図形の座標が画面の外にあるとき

グラフィック画面は横 0〜639、縦 0〜199 です。範囲を外れた座標の扱いは、PSET / PRESET / LINE（`B` / `BF` を含む）/ PAINT / CIRCLE の中心 / CONNECT の各点に共通です。

- 横方向は 640 以上を 639 に丸めます。負の値も同じ経路で 639 になります。
- 縦方向は 200〜255 を 199 に丸めます。0〜255 を外れる値（256 以上と負の値）は `Illegal Function Call` になり、その文は何も描きません。

丸めは座標を読み取った時点で行います。`LINE (410,18)-(4318,191)` は `LINE (410,18)-(639,191)` として描かれ、`CIRCLE (700,100),30` は中心を `(639,100)` に寄せた円になります。傾きを保ったまま画面の枠で切り取る動作ではありません。

### 図形の引数に小数を書いたとき

引数の種類ごとに整数化のしかたが違います。

| 引数 | 整数化 | 例 |
|------|--------|----|
| 横方向の座標 | 0 方向へ切り捨て | `PSET (100.6,10,2)` → 横 100 |
| 縦方向の座標 | 最近接へ丸め（端数 0.5 は 0 から遠い側へ） | `PSET (100,10.6,2)` → 縦 11 |
| 半径（CIRCLE） | 0 方向へ切り捨て | `CIRCLE (100,100),20.6` → 半径 20 |
| パレットコード・塗色・境界色 | 最近接へ丸め | `PSET (0,0,3.7)` → パレットコード 4 |
| SYMBOL の倍率 | 最近接へ丸め | `SYMBOL (0,0),"A",1.7,1.7` → 倍率 2,2 |
| COLOR の文字色・背景色 | 最近接へ丸め | `COLOR 3.7` → 文字色 4 |
| COLOR= のパレット番号・カラーコード | 最近接へ丸め | `COLOR=(3.7,5.7)` → 4 番へ 6 |

`PSET (X,Y,RND*8)` や `COLOR=(5,RND*8)` のように色を小数式で決めるプログラムでは、切り捨てと丸めの違いがそのまま色の違いになります。

## 6. 音楽ステートメント

### 6.1 PLAY

```
PLAY 文字列式1[,文字列式2[,文字列式3]]      （最大 3 声）
```
例: `PLAY "T120O4L4CDEFGAB","O3L2CEG"`

各文字列式には、演奏内容を綴った制御文字列（MML）を書きます。使える綴り:

- 高さを決めるもの … `On`（オクターブ 1〜8）／`A`〜`G`（音名。後ろに `#`・`+`・`-` を付けて半音）／`Nn`（オクターブと音名を使わず、1〜96 の通し番号で高さを直接指定）
- 長さを決めるもの … `Ln`（長さ 1〜64。後ろに `.` を付けると付点）／`R`（音を出さずに長さだけ進める）／`Tn`（テンポ）
- 響きを決めるもの … `Vn`（音量 0〜15）／`Sn`（エンベロープ形状）／`Mn`（エンベロープ周期）

演奏の扱い:

- 割込み駆動のバックグラウンド演奏で、演奏中も次の文へ進みます。通常の BASIC の文法エラー・実行時エラーでは演奏を止めません。STOP、BREAK キー、RUN は演奏を停止します。

### 6.2 SOUND／BEEP

```
SOUND レジスタ番号,データ      （0〜13, 0〜255）
BEEP
```
例: `SOUND 8,15`

### 7.3 MID$ 文（文字列の部分置換）

```
MID$(文字列変数,開始位置[,長さ]) = 文字列式
```
例: `A$="ABCDE" : MID$(A$,2,3)="XYZ" : PRINT A$` → `AXYZE`

- 開始位置（1 起点）から右辺の内容を上書きします。**置換で文字列の長さは変わりません。**
- 実際に書き換わるのは「長さ」「右辺の長さ」「開始位置から末尾までの残り」のいちばん小さい値のバイト数です。右辺が長すぎれば切り捨て、短ければその分しか書きません。「長さ」を省いたときは右辺の長さがそのまま指定長になります。
- 開始位置が 1〜文字列長の範囲外（0・負・長さ超過）、および長さが 0〜255 の外は `Illegal Function Call`（コード 5）になります。
- 左辺が文字列変数でないとき、右辺が文字列式でないときは `Type Mismatch`（コード 13）です。

## 9. 実行時エラーの表示とエラーコード

### 9.1 表示の書式

実行時エラーが起きると、エラー名と発生行番号を次の書式で表示して直接モードへ戻ります。

```
<エラー名> In <発生行番号>
```

例:

```
10 PRINT "START"
20 A=SQR(-1)
RUN
START
Illegal Function Call In 20
Ready
```

直接モード（行番号を付けずに打ち込んだ命令）で起きたエラーには、発生行が無いので `In <行番号>` を付けません。

```
ERROR 5
Illegal Function Call
Ready
```

`ON ERROR GOTO` でトラップした場合は表示を行わず、登録した行へ分岐します。飛び先では `ERR`（エラーコード）と `ERL`（発生行番号）を参照できます。`ERR` は下表の**エラーコードそのもの**を返します（`IF ERR=53 THEN …` のように書けます）。`ERR` は `RESUME` を通ると 0 に戻ります（[3.6 ERROR／RESUME](#36-errorresume)）。

### 9.2 エラーコード一覧

エラーコードは 1〜26 と 50〜73 で、27〜49 は欠番です。表示はいずれも F-BASIC 文法書 付録 5 のエラー名です。`ERR` が返す値は下表のエラーコードです。

| 8 | `Undefined Line Number` | 分岐先または実行開始位置に指定した行番号が存在しない |
| 9 | `Subscript Out Of Range` | 添字が宣言した大きさの外を指した |

| 58 | `Bad Data In File` | ファイル中のデータの形が期待した形式と合わない（アスキー形式でないファイルの `LOAD` ／ `MERGE` もこれになります） |
| 59 | `Device In Use` | 使用中の装置を重ねて確保しようとした |
| 60 | `Device Unavailable` | 指定した装置を使える状態にできなかった |
| 61 | `Buffer Overflow` | 入出力バッファに収まらない量を渡した |
| 62 | `Protected Program` | 保護されたプログラムに対して許されない操作を行った |
| 63 | `File Not Found` | 指定した名前のファイルが見つからなかった |
| 64 | `File Already Exists` | 同じ名前のファイルがすでにある |
| 65 | `Directory Full` | ディレクトリ領域がいっぱいで、新たなファイルを登録できない |
| 66 | `Too Many Open Disk Files` | 確保されているファイルの個数を超えて開こうとした |
| 67 | `Disk Full` | ディスクがいっぱいで、データを登録できない |
| 68 | `Field Overflow` | フィールドの長さが 256 バイトを超えている |
| 69 | `String Not Fielded` | `FIELD` 文で宣言していない文字変数に `LSET` / `RSET` で代入しようとした |
| 70 | `Bad Record Number` | 指定したレコード番号は存在しない |
| 71 | `Bad File Structure` | ファイルの構成に誤りがある |
| 72 | `Drive Not Ready` | 指定したドライブは Ready 状態にない |
| 73 | `Disk Write Protected` | ディスクが書込み保護されている |
| 74 以上 | `Unprintable Error` | 定義されていないコード |

65〜73 のうち、本実装が自ら送出するのは 65 と 67 です。それ以外は `ERROR <番号>` 文で発生させたときに現れます。

### 9.3 既知の相違

- **`GOSUB`／`ON〜GOSUB`／`FOR` の入れ子が深すぎるとき**は `Out Of Memory`（コード 7）になります。入れ子の枠は文字列領域の直下に置きます。段数に固定の上限はなく、プログラム・変数・配列・文字列領域などを除いた空きメモリが尽きるまで積めます。

## 10. F-BASIC にあり 7T-BASIC で未サポートの予約語

F-BASIC 文法書の V3.0・ROM モードに予約語として載っている語のうち、7T-BASIC がサポートしていない 18 語と、ディスク専用の `DSKF` / `DSKINI` / `NAME` の 3 語を補足した一覧です。

「区分」は 2 つに分かれます。**対象外**は本実装が扱わない機能（プリンタ、バブルカセット、モニタ、ディスクの管理）に属する語で、ROM モードの 8 語とディスク専用の 3 語を合わせて 11 語です。**未対応**はそれ以外の 10 語です。「挙動」の「無視」は受理されるが何も起こらないもの、「エラー」は書くとエラーになるものです。

| 予約語 | 区分 | 挙動 | 備考 |
|---|---|---|---|
| BUBINI / BUBW / BUBR | 対象外 | 無視 | バブルメモリ非対応 |
| COM | 未対応 | 無視 | RS-232C 制御なし |
| COMMON | 未対応 | 語自体なし | 変数名として解釈されます |
| DSKF | 対象外 | 語自体なし | 変数名として解釈されます。ディスクの空きクラスタ数は返せません |
| DSKINI | 対象外 | 語自体なし | 変数名として解釈されます。ディスクの初期化は行いません |
| EOF / LOF | 未対応 | 常に 0 | 開いたファイル番号に対する入出力を持たないため、状態を返せません |
| HARDC | 対象外 | 無視 | ハードコピーなし |
| KILL | 未対応 | 無視 | |
| LLIST / LPRINT | 対象外 | 無視 | プリンタ出力なし |

| MON | 対象外 | 無視 | モニタなし |
